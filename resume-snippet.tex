\item \textbf{Huntly}
\href{https://github.com/Ank0it/Huntly}{GitHub: \faGithub} \\
\textit{Node.js, Express.js, MongoDB, Mongoose, JWT, Cloudinary, Multer, bcrypt}
\begin{itemize}
  \item Built \textbf{Huntly} to challenge growth-first platform design — a privacy-focused video-sharing backend where users retain clear ownership of their media and profile data through minimal data collection and predictable token-based access control.
  \item Implemented end-to-end platform modules: \textbf{JWT auth} (access + refresh tokens with rotation and bcrypt password hashing), \textbf{video publishing} with publish/unpublish toggling, and social features including \textbf{subscriptions, comments, likes, playlists, and tweets} for a complete content-sharing workflow.
  \item Engineered a \textbf{cloud-first media pipeline} using Multer for multipart uploads, Cloudinary for remote storage with \texttt{public\_id} tracking to reliably clean up replaced avatars/covers, and Mongoose aggregation pipelines for channel analytics and watch history — all config-driven via environment variables.
\end{itemize}

\item \textbf{Huntly}
\href{https://github.com/Ank0it/Huntly}{GitHub: \faGithub} \\
\textit{Node.js $\cdot$ Express.js $\cdot$ MongoDB $\cdot$ Mongoose $\cdot$ JWT $\cdot$ Cloudinary $\cdot$ Multer $\cdot$ bcrypt} \\
Privacy-first video-sharing platform backend; built RESTful APIs for user authentication (JWT access/refresh tokens with bcrypt password hashing), avatar and cover-image uploads via Cloudinary (with automatic deletion of previous assets by \texttt{public\_id}), and a full data model spanning users, videos, comments, likes, playlists, subscriptions, and tweets.
